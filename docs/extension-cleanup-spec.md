# 浏览器助手 0.3.0：当前页读取

## 审查发现
0.2.5 默认页混合批次诊断、恢复授权、旧单岗状态机、结构诊断与官网填写。详情按钮位于旧单岗折叠区并依赖旧记录，不支持直接在已打开详情开始；用户看不到可运行入口。README同时称0.1.9、0.2.3、0.2.4为当前版本。无需构建：浏览器直接加载browser-extension/manifest.json及popup.html。

## 决策
- 学校当前详情读取为首页主按钮，不依赖旧任务、不点击网页、不打开/关闭标签。
- 详情有独立ID时自包含核对；没有ID时须先读取当前列表并明确记住一个唯一ID/标题/公司/学期，再由本人打开详情。绑定24小时失效，身份不完整/冲突拒绝输出。
- 只读取学校已允许路径的可见字段；缺时长明确未知，保留原文和学期，不推断。认证、内嵌页、不可识别结构、限额、权限失败给安全错误码和下一步。
- 最近一次已验证结果保存在扩展专有本地数据库，关闭弹窗可恢复下载；新失败不可冒充旧成功。不触碰旧记录或浏览器登录资料。
- 导出单岗JSON，应用已有预览→确认→事务导入；服务端重新匹配本账号ID/标题/公司/学期、校验正文/时长证据及版本。未知不覆盖已有时长，保留本人确认渠道/提交记录。
- 保留Greenhouse配对、预览、确认普通文本填写；不提交、不扩大权限。
- 自动开页/批次/恢复授权/旧诊断按钮退出运行包；旧模块与断言迁至历史测试夹具，可回溯，不作为当前功能。诊断只提供当前读取错误码，无门户正文/凭据。
- 不申请可选学校全站权限；activeTab+scripting及既有localhost权限保持。不会主动撤销用户已有授权或改浏览器设置。

## 验收
1. 初次打开即可看见并触发详情读取；缺身份时明确引导列表绑定，无旧任务依赖。
2. 独立ID成功、无ID绑定成功、ID/标题/公司/学期冲突、过期绑定、重复列表、缺时长、超限、登录、frame与权限失败。
3. 切页/失败禁用本轮导出；旧结果清晰标注，可重新打开恢复；无自动导航或提交。
4. 隔离真实MV3及合成页面验证弹窗、窄屏、导出、恢复；合成数据经现有应用预览和确认导入，重复导入与提交历史保护。
5. 官网填写回归保持；最终完整串行测试、语法及diff检查。真实两岗手动读取与保护导入单独验收，不把合成自动导航成功当实测。
