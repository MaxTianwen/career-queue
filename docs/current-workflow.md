# 当前工作流与验收边界

工作台合并公开和学校岗位，保存来源、去重、失败原因及未知事实。国家/方向/任期/时长过滤、卡片/表格及学校/官网分渠道历史保留。每日后台搜索关闭；打开已登录应用和手动刷新仍可搜岗。网页保活与OpenClaw Gateway分离。

只有用户选择岗位后准备材料，事实审查、版本与实际提交独立。材料生成不等于投递；学校已提交不推断官网已提交，未知日期留空。

## 浏览器助手0.3.0

主流程为本人打开详情→**读取当前详情页**→核对身份/学期/时长原文→**下载岗位JSON**→工作台预览/确认导入。缺独立School ID时先在当前列表明确选择并记住目标，再由本人打开详情；无旧试运行依赖，无自动导航。两岗真实当前页手动读取和保护导入已验证。明确学校字段优先于正文通用政策；公民限定仅按明确原文排除，保留来源与申请历史。

官网Greenhouse普通文本填写保持本人预览确认；不点最终提交。诊断集中于折叠入口。旧0.2.x批次授权、恢复和自动开页已退出运行包，历史模块仅保留在测试夹具，不再作为可用产品入口。安装目录、准确按钮、权限、测试与最少人工步骤见[扩展说明](../browser-extension/README.md)。

代码、合成测试和通用文档可审阅；真实岗位JSON、数据库、求职材料、运行日志及备份只保留在private/output。本次发布仅包含代码、合成夹具与通用文档，不包含真实读取文件或运行数据，不改变用户浏览器安装或登录设置。
