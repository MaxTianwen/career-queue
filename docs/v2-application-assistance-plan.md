# 下一功能阶段：本机申请辅助准备

2026-10-05，发布后候选范围，用户“继续”后已按推荐方向实现本机草稿与核对，见 releases/v2.4.0-verification.md。不是自动投递功能已经完成。

## 现状与可复用部分

- 已有逐岗位申请渠道、独立官网/学校提交历史、当前依据绑定的材料审阅与PDF，以及生成/编辑前开放复查。
- 现有保存职位包含JD和官网链接，但没有表单字段结构；JD不等于申请表，不能声称能从JD读出全部必填问题。
- 当前生成是本地受控重排与本人逐句编辑，没有模型语义改写。历史知识库不得替代当前简历，也不得猜测资格或个人答案。

## 推荐首个完整结果

用户选定保存职位后，在本机整理本次申请的材料、实际申请入口和本人录入的问题/答案，核对后跳转本人处理。已有材料和提交版本沿用，不因准备内容变化而改写历史。

具体字段和保存规则需在实施前结合用户答复确定；不先建立通用浏览器代理、网站账号管理或新模型服务。

## 后续网页辅助边界

首批网站、可填写字段和最终提交方式须明确后实施。浏览器遇到登录、验证码、无法识别的必填题或上传失败，应暂停并保留进度。打开页面、填表或点击按钮均不能自动记为提交成功。

## 验收要求

账号隔离；当前简历/JD/材料变化提示重新核对；失败保留输入；不移动官网/学校历史；键盘及窄屏可操作。正式申请不能用于合成测试。
