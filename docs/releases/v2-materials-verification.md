- 材料绑定当前启用简历的文件和文字哈希、岗位身份 / JD、实际 PDF 原件和哈希。JD / 身份 / 基准改变要求重新审阅，修改备注不使材料失效。旧版本仍可预览下载。

- 仅记录用户声明的结果，未对真实学校或雇主提交进行外部核验。现阶段提交记录只读，不提供覆盖 / 撤销；后续若增加纠正应保留审计。
