## 明确限制与后续

- 已保存学校关联当前不可改绑 / 解除或更新来源字段；新粘贴有变化时只显示差异，避免覆盖申请历史。下一候选是为这些维护动作设计预览与审计，不自动实施。
- 一个已保存职位目前关联一个学校 ID；同雇主编号的多个学校 ID 提示核对，冲突不自动合并。
- 不自动登录学校或抓取完整学校 JD；发现结果仍来自已接入的有限公开来源。用户须粘贴完整 JD，并自行核实实际申请要求。
- v1 正式资料迁移、v2 定时发现及远程邀请需独立范围和验收；未将旧正式数据自动复制到 v2。package 仍 1.5.0，作为 v2 内部完整里程碑，不另拆补丁。
