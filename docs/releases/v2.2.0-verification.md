## 行为

- 准备生成对照或编辑草稿时复用受限官网读取器，显示开放依据与核查时间。明确关闭拦截，HTTP 失败/不支持的链接为未知，允许本人到实际入口核实后确认。
- 核查绑定账号会话、当前岗位/简历和学校来源；15 分钟、输入变化、重新核查或服务重启后旧确认失效。生成前及保存结果前均检查，前端伪造状态不能绕过。
- 无官网链接不抓取，学校截止过期拦截学校无外链岗位；学校截止不会冒充有外链岗位的官网截止。不覆盖保存的 JD，不自动修改提交历史。
- 重新核查保留要点选择与编辑文字，清除开放确认。仅短时运行内存保存核查结果，不新增持久审计表，不宣称它是申请成功证据。
