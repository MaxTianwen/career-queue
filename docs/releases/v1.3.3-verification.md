## 已复现与修复

- `pollAutomation` 在发出请求前保存展开面板列表。通过延迟响应复现：请求等待期间关闭历史、打开后台检查详情，响应返回后两项操作被之前的快照覆盖。成功和失败响应均能复现。
- 调整为在响应完成后、替换内容前读取两个面板各自的当前状态，保留等待期间的用户操作。
- 通过让两个请求乱序返回复现：较新的响应已确认暂停，旧成功却显示启用，或旧失败显示连接待核实；较新的连接失败也可能被旧成功错误地恢复为已启用。
- 给页面状态请求增加递增编号，只接纳最后发起的请求。较早的成功或失败均不再修改状态、提示或面板。当前请求失败仍保留上次完成结果，并禁用未核实的日程开关。
