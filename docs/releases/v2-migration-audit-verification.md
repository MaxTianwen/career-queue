# v2.1 迁入阶段：来源与审计（2026-10-05，本机完成、未发布）

本轮实现来源记录，不是正式导入器。当前 package 仍为 2.0.0；与后续迁入流程合并为功能阶段，不拆成单表单补丁。

## 实现

- “数据与容量 → 旧版迁入记录”显示旧 Key、记录 ID、登记时间、当时职位名称、旧版职位快照，以及历史文件的旧版本、基准标识和 SHA-256。
- 来源记录按账号隔离；文件与职位必须属于目标账号，文件哈希核对、重复引用拒绝。同一旧 Key 的相同映射重试返回原记录，来源变化拒绝覆盖；后续职位编辑不改变旧快照。
- 历史文件固定标为“历史生成稿，未审阅”。登记不创建审阅版本、当前简历、生成链、学校关联或提交记录。
- 网页仅有 GET 读取接口，没有写入迁入记录或正式导入的 HTTP 接口。维护方法不执行文件或职位导入，后续导入器仍需设计事务与确认。
- 个人导出包含来源记录，完整备份恢复保留记录和文件引用。退出账号清空页面中的来源内容。
