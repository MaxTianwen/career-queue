# v2 本机完整流程验收

日期：2026-10-04。分支 codex/v2.0-prep；package 仍为 1.5.0，v2 未正式发布、未推送。

## 结论

本机阶段的完整账号流程已通过：注册 / 登录 → 本人简历核对启用 → 独立偏好与建议 → 保存岗位 → 真实材料生成或 PDF 上传 → 预览审阅 → 两渠道独立提交记录 → 改密 → 备份恢复 → 本人资料包导出。远程邀请部署尚未实施，不能将本机通过当作公网就绪。

本轮新增 test/v2-journey.test.mjs，将此前分散的功能验收串成可重复的实际 HTTP 流程。没有发现需要修改产品逻辑的新缺陷，不另立补丁版本。

## 首次失败与工具限制

- 首次集成测试的合成简历过短，触发既有 PDF 可提取正文长度检查。补充合成要点后重跑通过；没有降低正式校验门槛。保留 journey.txt 与 journey-retry.txt。
- restored-school-narrow.png 及其整页重试图出现挤压，图像与 DOM 布局读数不一致。重置测试尺寸后，可见区域截图 restored-school-viewport.png 已查看：390px 单列布局正常，无横向溢出。本轮不将异常整页截图当作通过证据，也不据此修改未复现缺陷的 CSS。
- 结束浏览器验收时桌面 ChatGPT 应用崩溃。独立应用日志及 Crashpad 显示重复发生于关闭内置浏览器验收标签页附近；这是桌面宿主排障，不是已定位的 Career Queue 产品缺陷。后续退出测试账号并复用标签页，暂不通过自动化关闭内置浏览器标签；底层修复仍需宿主崩溃堆栈。详见本机 output/v2-acceptance/desktop-crash-diagnosis.md。
