## 交付范围

- 从本人已核对启用的 DOCX 读取结构；先展示同一经历、同格式相邻要点的原文、建议顺序、来源段落和相关 JD 行。每组明确保留或接受；没有可安全重排的内容时按原文导出，不编造改写。
- 生成前本人核实岗位仍开放；JD 中明确可识别的过期截止会阻止生成。v2 尚未接官网开放状态自动复查，确认不保存为通用资格或开放状态。
- 独立账号 / 随机工作目录；隐藏、只读 Word 导出基准和生成稿，二者均须一页。复用既有格式验证器，检查 XML 非修改部分、字体 / 字号、页尺寸、文字与文件哈希；原稿和当前评分简历不变。
- DOCX / PDF 在同一事务保存为本人文件，PDF 自动选入材料，刷新后可以继续使用。生成成功不代表本人已审阅或已提交；预览后仍需明确保存审阅版本。
- 保留生成时的简历 / JD / 重排选择。旧稿依据变化或属于另一岗位时，不能成为当前岗位的新审阅版本；旧材料和已提交历史仍保留。
- 无当前 Word、结构不支持、渲染失败、超过一页、期间退出登录、输入变化或容量不足时，不发布半套材料，也不回退 v1 的个人模板。
