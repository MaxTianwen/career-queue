## 跨区域输入保护

修复前：在隔离虚构岗位中先输入未保存备注，再保存学校关联，关联成功但详情整体刷新后备注变为空，dirty 标记消失。

用户确认的方案现已实现：

1. 完成用户点击的那项保存，只清除该表单的修改标记。其他输入保留在原控件中，不暗中保存；需要重读的详情延后刷新并显示提示。
2. 最后一处输入保存成功后读取最新详情；失败继续保留输入和待刷新状态。用户也可明确选择放弃未保存修改并刷新，取消确认不会丢失输入。
3. 已成功保存、尚未重读的表单保持锁定，保存另一区域或失败重试不能意外解锁它，避免重复确认旧状态。
4. 岗位复查和材料区域刷新也遵守未保存保护；发现页读取期间新输入的文字不会被迟到响应替换。切换职位或关闭后清理旧的待刷新状态。
