# 机会清单整理（本机，未推送）

用户要求两个去除方式：放回原职位清单，或隐藏并提供恢复入口。

- 机会清单卡片提供“放回职位清单”和“不需要，隐藏”。
- 放回后在“发现机会 → 放回的职位”保留个人记录，点击“重新加入机会清单”恢复。即使公开来源已不再列出该职位，也不会丢失恢复入口；明确提示核实是否仍开放。
- 隐藏后通过机会清单右上方“查看已隐藏”恢复；发现结果不重复展示已经保存、隐藏或放回的同 URL 职位。
- 操作仅改变本人职位的列表状态。原 ID、备注、材料、学校关联与投递历史保留，未删除记录。未保存编辑沿用原来的放弃确认。
