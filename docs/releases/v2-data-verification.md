日期：2026-10-03（多伦多）。codex/v2.0-prep，package 仍为 1.5.0；本阶段未提交、未推送，不是完整 v2.0.0 发布。

## 交付与边界

- 数据与容量入口显示当前账号的文件数量 / 字节、岗位数量与 Word 工作目录占用。没有扩大额度或自动清理文件。
- 本人资料包包含已保存职位、偏好、当前基准、解析文字、申请渠道、不可变材料 / 生成版本、提交记录和原文件。导出按账号隔离，管理员也不能取得其他人的资料；密码哈希、会话、公共职位目录与未保存输入不导出。ZIP 用于查阅保管，本期不支持个人包导入。
- 本机维护命令生成完整数据库一致性副本，检查数据库完整性、外键及每个文件的字节数 / SHA-256。使用 Node 的 SQLite backup API，不复制正在运行的主数据库文件冒充完整备份。API 说明见 [Node 官方文档](https://nodejs.org/api/sqlite.html#sqlitebackupsourceDb-path-options)。
- 副本清除活动会话、临时 PDF 预览确认和登录尝试计数，保留已审阅材料与实际提交历史；原工作区不改。完成校验后才写入清单；不完整副本不能恢复。
- 恢复先核对清单和哈希，只建立新目录，再校验数据库和文件；已有目录拒绝覆盖。恢复不合并、不切换当前服务；故障或中断残留保留，不自动删除。
- 完整备份含所有账号与密码哈希，未加密，仅本机维护命令提供，不开放网页下载；须作为私人资料保管。原 v1 / Notion、运行环境配置与 Word 临时工作目录不包含在内。已保存原件、已发布生成稿在数据库中保留。
