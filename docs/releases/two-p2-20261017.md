# Explicit start months and passive preview list stability

Explicit start dates now retain their month when determining internship terms: `Start Date: May 2027` matches Summer 2027 even when the title only supplies the same year. End, graduation and publication dates do not supply start terms; conflicting title years retain priority.

A successful passive `POST /api/files/<uuid>/view` no longer invalidates in-flight list reads. Actual writes and account changes still invalidate or reject stale results. The exception is limited to the exact passive preview route.

Validation: the exact six-file candidate passed 1,034 serial tests including local Windows Word/PDF (zero failures or skips), 35 targeted checks, and 96 isolated browser checks at 1280px and 390px. After applying the candidate, a further 33 targeted checks passed. Local service health, page response and the three relevant served modules were verified. No authenticated production browser journey or public deployment is claimed.

Source and database backups were verified with an isolated restore before restarting the local v2 service. All 38 production table fingerprints remained identical; registration, mail and account settings were unchanged. The older dashboard service was not restarted. Private evidence and backups are excluded from this commit.

Rollback: restore only these scoped source changes after comparing subsequent edits, or revert this commit, and restart v2 under the same controlled procedure. This release does not change the database schema or require a database rollback. Database restore is a separate operator action and intentionally revokes old sessions.
