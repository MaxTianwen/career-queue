## 本版变化

- Genesys 固定公开雇主列表进入原搜索流程，不是全 Workday 搜索。采用官网前端的公开列表端点，无登录、密钥或申请写入；该端点不是承诺稳定的通用 API。每页 20 条、最多 25 页，超限 / 分页异常 / 网络失败保留 partial 或 failed，不能显示完整覆盖。后续页 total 为 0 的实际行为已覆盖测试。
- 官方 JobPosting 继续负责完整 JD 与日期；列表的 Posted Today / Days Ago 不换算为首次发布日期。多个地点的简略列表先读取详情，不能仅因 `2 Locations` 漏掉加拿大岗位。
- 学校复制内容支持拆行表头、空状态格、末尾可选制表符，以及 Apply / Applied。学校 ID 与雇主编号分开；来源写着已提交也不自动更新本人投递状态。
- 预览学校列表时，只读比较最近发现结果和预筛记录。显示正文失败、官网截止、条件排除或来源缺口；旧快照缺证据不猜原因。采用候选链接返回字段修正，必须重新匹配并勾选后保存。
- 归组卡片内不同招聘编号分别提供自己的链接与正文依据；不会用主职位链接代替匹配到的另一编号。地点 / 批次不同继续显示冲突供核实。
- 官网明确写 beginning in May/June 2027 可归为 Summer；跨季或无依据保持未知。
