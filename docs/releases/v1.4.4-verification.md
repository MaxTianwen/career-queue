# v1.4.4 本机验收

日期：2026-10-02（America/Toronto）。package 1.4.4，用户已授权发布；上一发布基线 v1.4.3 / 389b31c。发布清单单独记录内容哈希。

## 已完成范围

- 学校候选补齐官网链接时，按规范化官网链接识别已有申请，展示两条记录的公司、标题、批次、地点、状态、材料有无和已保存备注。用户单独确认后才迁移学校关联。
- 按用户本轮确认的规则，只迁移学校关联：原候选归档并保留备注、来源和历史；已有职位的材料、官网投递状态及备注不被替换。提供回看原候选和定位已有职位的入口。重复学校 ID 导入复用已有记录。
- 学校已提交、原候选有材料（含 Notion 附件）、公司 / 招聘编号 / 批次冲突、已有其他学校关联或多个同链接目标时暂停。无自动同名合并，无记录删除。
- Notion 没有两页事务：先保存目标关联，再归档原候选。中断期间可暂时看到两条学校关联，凭据保存在目标记录中；重试继续收尾，不重复写入历史。中断期间学校状态修改受阻，重新打开原候选可恢复官网链接。不会把两次写入表述成原子操作。
- JD 明确说明多种工作方式可选时，显示各选项并参与相应筛选；不将含有多个关键词的任意句子视为任选。原句及地点限制保留，字段冲突 / 未知仍待核实，不推断加拿大远程资格。

## 保留的限制

- 学校迁移写入为隔离数据验收；未拿真实申请做 Notion 测试写入。Notion 页面被外部同时编辑没有跨页事务保证；版本检查会阻止已发现的冲突，中途异常保留两条记录供继续收尾。
- 工作方式为保守本地句式提取，不能保证识别所有雇主表达；明确未匹配的句式需按实际案例扩展，不靠关键词数量猜测。
- 本轮未新增简历生成能力，也未重新验收真实学校提交或材料专项页面。既有原生 200% 缩放、原生确认框与材料特定视觉验收限制继续保留，不以本轮桌面 / 窄屏检查冒充通过。
- 用户已确认发布本版；随后开发 v1.4.5，v2.0、多用户、半自动投递和模型接入仍未开始。
