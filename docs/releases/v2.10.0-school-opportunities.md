# v2.10.0 学校职位模块（本机未推送）

新增独立学校职位页，不进入公共发现缓存。学校对照粘贴后点击“更新学校职位并对照”，按账号与 School ID 更新来源资料。未出现在本次列表的旧岗位保留；无效或重复 ID 的批次拒绝更新，原资料不变。

学校职位可直接进入现有材料与申请工作区。已有关联复用原职位；未关联时明确点击准备申请后建立学校候选，不猜测官网关联或提交渠道。学校关联职位从普通机会清单区分展示；已有学校关联也会出现在新模块。来源更新记入原关联审计，不移动官网提交和材料，不覆盖冻结的学校提交快照。

个人资料导出包含学校职位来源；完整 SQLite 备份包含新表。正式启用前已完成本机备份。58 项工作区回归通过，新增学校模块定向复验通过。覆盖重复导入、学校来源更新、跨账号隔离、旧页面拒绝、缺席行保留和申请记录不变。没有进行本轮浏览器交互/视觉验收，不宣称通过。

合并之前未发布的配对入口改进，取代独立 v2.9.1 发布计划。不推送、不接入模型，不自动提交学校或官网申请。
