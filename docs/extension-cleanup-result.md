首页直接读取当前学校详情；缺独立编号时，从可见列表明确选择身份，再由本人打开详情。成功JSON通过已有预览、确认及指纹检查导入。原Greenhouse预览和确认普通文本填写保留。

旧批量开页、恢复、暂停及多版本诊断退出运行包，历史模块保留在测试夹具。当前版本不提供自动开页或批量读取；未来实现不得把历史合成检查当真实门户验收。

服务端核对本账号已有ID、标题、雇主、学期及源字段。已核验学校学期和时长优先于正文通用政策；未知时长不猜测，原始正文不改写。重贴列表保留证据，重复导入幂等，保留本人确认渠道和申请历史。明确公民限制按原句排除，来源仍保留。
