## 运行

需要 Node.js 22+。在项目目录执行：

```sh
npm run start:v2
```

打开 `http://127.0.0.1:4322/`，使用已有本机账号；若后台服务已运行，直接打开网页。创建本机账号可用 `npm run admin:v2`。旧版个人工作流使用 `npm start`（4317）；两个版本不会自动迁移数据。私有配置、数据库和个人材料不包含在仓库中。

新检出目录使用文档读取、生成、预览或完整集成测试前，需要在本机私有文件 `private/v2-local/runtime.json` 中配置 `python` 为已安装 Python 的绝对路径（例如 `{"python":"C:/path/to/python.exe"}`）。保留已有配置，不要覆盖。Python 文档依赖可用 `python -m pip install -r scripts/requirements-test.txt` 安装。现有本机Word生成/重新排版流程需要 Microsoft Word；离线返回包的PDF检查和预览使用Python库，不会将返回的Word重新交给Office渲染。完整测试还包含旧版文档流程，需要在 `private/resume-templates/templates.json` 配置同样的 `python` 字段；已有文件应保留其他字段。两个配置文件均不提交。

## 当前功能

- 打开已登录应用或手动刷新时发现公开岗位；合并来源、去重、保存失败原因和现有结果。后台每日搜索已关闭。
- 加拿大（默认）/美国/全部国家、CS/嵌入式/Data、任期和时长等筛选，支持卡片/表格视图。未知事实保持未知；不把岗位地点或模糊条件推断成工作许可。
- 学校岗位按School ID保存。明确的Application Submitted可同步学校申请历史并从待申请视图隐藏；缺行不撤销历史，未知日期留空，不推定官网也已提交。
- 明确公民限制按账号规则排除并保留证据，未知或冲突要求留待核实。学校和官网申请分别记录。
- 选定岗位后准备简历、求职信或问答。材料完成不等于已提交；保留事实审查、版本和本人最终确认。
- 网页后台保活与OpenClaw Gateway已分离；OpenClaw不是当前手动发现的运行依赖。不会自行启用日程。

## 离线批量文书

1. 在发现列表选择1–5岗，指定本人上传的CS/Data Word原稿和通用CL原稿；未知分类需要本人选稿。
2. 导出前就地查看**实际导出的JD正文**、来源链接和抓取状态。缺正文不能导出；短而有效的正文不会因字符数被拒绝。截断提示只是提醒。人工核对绑定当前正文指纹，正文改变后旧确认失效；未核对状态会明确写进任务包提示词。
3. 查看容量提示后下载任务ZIP。自行选择外部AI或人工编辑工具处理；这是由本人操作的离线交换，应用没有付费模型API或自动外发。保留原件及事实边界，返回包根目录放 `return-manifest.json`，每岗包含清单指定的简历与CL的DOCX/PDF及改动记录。
4. 上传返回ZIP，查看逐岗检查结果并选择有效岗位导入。缺失或损坏文档只影响对应岗位；宏、脚本、危险路径等仍整包拒绝。成功后焦点移到结果，失败移到错误提示；结果仍需人工核对，未记录申请。

A后再导入同版本A+B只新增B；不同JD、源版本或成品保留独立结果，旧记录不删除。同账号同用途同格式的相同字节可复用。每账号仍限20个文件/20MB（含原稿及归档文件），导出提示按每岗4份新文件保守计算，导入按真实字节与复用量复核；支持减少所选岗位，不一概禁止导出5岗。

现有“原文重排”功能只按本人审阅决定调整原句，不是语义定制。离线导回会检查PDF实际单页、可渲染及Word/PDF词序；不证明Word最终版式、事实真实性、资格或ATS效果，不保证通过筛选。

## 数据与安全边界

`private/`、`output/`、`.env`、数据库、学校诊断导出、简历/求职信及运行时备份属于本机私有数据，不提交。公开文档也不得包含真实学校编号、个人资格/联系信息、申请清单数量、原始学校正文、用户目录或具体备份位置；公开岗位本身及通用配置示例可以保留。`SCHOOL-*` 是文档脱敏标签，不是可使用的学校编号。

发布前检查 `git diff --cached` 和 `git diff --cached --name-only`；`.gitignore` 不会清除已跟踪文件或历史。发现疑似凭据时先由凭据所有者撤销或轮换，再决定是否另行处理历史。普通脱敏提交仍保留旧提交、分支/标签及外部缓存中的内容，不代表彻底删除。使用`.env.example`理解配置项；不要将凭据粘贴进代码或日志。材料不得编造经历，也不宣称未经验证的ATS通过率。

当前变更和待验收范围见 [工作流说明](docs/current-workflow.md)。较早版本设计与运行记录仅供历史参考，以当前行为及明确验收结果为准。
