## 运行

需要 Node.js 22+。在项目目录执行：

```sh
npm run start:v2
```

打开 `http://127.0.0.1:4322/`，使用已有本机账号；若后台服务已运行，直接打开网页。创建本机账号可用 `npm run admin:v2`。旧版个人工作流使用 `npm start`（4317）；两个版本不会自动迁移数据。私有配置、数据库和个人材料不包含在仓库中。

新检出目录使用文档读取、生成、预览或完整集成测试前，需要在本机私有文件 `private/v2-local/runtime.json` 中配置 `python` 为已安装 Python 的绝对路径（例如 `{"python":"C:/path/to/python.exe"}`）。保留已有配置，不要覆盖。Python 需具备项目脚本使用的文档依赖，Word/PDF 渲染还需本机 Microsoft Word。完整测试还包含旧版文档流程，需要在 `private/resume-templates/templates.json` 配置同样的 `python` 字段；已有文件应保留其他字段。两个配置文件均不提交。

## 当前功能

- 打开已登录应用或手动刷新时发现公开岗位；合并来源、去重、保存失败原因和现有结果。后台每日搜索已关闭。
- 加拿大（默认）/美国/全部国家、CS/嵌入式/Data、任期和时长等筛选，支持卡片/表格视图。未知事实保持未知；不把岗位地点或模糊条件推断成工作许可。
- 学校岗位按School ID保存。明确的Application Submitted可同步学校申请历史并从待申请视图隐藏；缺行不撤销历史，未知日期留空，不推定官网也已提交。
- 明确公民限制按账号规则排除并保留证据，未知或冲突要求留待核实。学校和官网申请分别记录。
- 选定岗位后准备简历、求职信或问答。材料完成不等于已提交；保留事实审查、版本和本人最终确认。
- 网页后台保活与OpenClaw Gateway已分离；OpenClaw不是当前手动发现的运行依赖。不会自行启用日程。

## 验证

```sh
npm run test:serial
```

Windows安装Microsoft Word时，可启用真实Word/PDF检查：

```powershell
$env:CQ_V2_TEST_PYTHON='C:\path\to\python.exe' # 指定已安装的 Python；新检出目录没有本机运行时配置
$env:CQ_V2_TEST_WORD='1'
npm run test:serial
```

没有独立lint/typecheck命令；修改的JS/MJS使用`node --check`并检查`git diff --check`。网络、Word、真实门户与模拟测试须分别报告，不能混称通过。

## 数据与安全边界

`private/`、`output/`、`.env`、数据库、学校诊断导出、简历/求职信及运行时备份属于本机私有数据，不提交。公开文档也不得包含真实学校编号、个人资格/联系信息、申请清单数量、原始学校正文、用户目录或具体备份位置；公开岗位本身及通用配置示例可以保留。`SCHOOL-*` 是文档脱敏标签，不是可使用的学校编号。

发布前检查 `git diff --cached` 和 `git diff --cached --name-only`；`.gitignore` 不会清除已跟踪文件或历史。发现疑似凭据时先由凭据所有者撤销或轮换，再决定是否另行处理历史。普通脱敏提交仍保留旧提交、分支/标签及外部缓存中的内容，不代表彻底删除。使用`.env.example`理解配置项；不要将凭据粘贴进代码或日志。材料不得编造经历，也不宣称未经验证的ATS通过率。

当前变更和待验收范围见 [工作流说明](docs/current-workflow.md)。较早版本设计与运行记录仅供历史参考，以当前行为及明确验收结果为准。
