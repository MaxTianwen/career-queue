## 原型边界

- 六个岗位、公司、JD、薪资、日期、评分及 Alex Chen 简历均为虚构示例，不是当前招聘信息或本人的真实履历。分数不代表 ATS 通过率或录取概率。
- 职位与材料编辑只保存在当前页面内存，刷新后清空；各页面的保存状态相互独立。没有模型、文件上传、DOCX / PDF 生成、Notion 写入或申请提交。
- 一页纸仅展示预览区域，不能代替真实模板、字体、页数和生成后的校验。正式版继续遵守原简历格式与材料确认规则。
- 发现、示例 Queue、详情和材料审阅可操作；学校待办、完整申请记录、简历上传与连接设置尚未制作成 v1.4 页面。选定方向后再应用到这些实际功能。
- `serve.mjs` 仅监听 127.0.0.1:4319，只提供明确列出的静态文件，没有写入 API；不读取工作区凭证、简历或真实日程。正式 4317 Dashboard 继续使用原代码。
