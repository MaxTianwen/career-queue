# Career Queue 本机填写助手（验收候选）

目前只支持 Greenhouse 官方岗位页的普通联系文本。未发布到扩展商店；首次需要本机安装。**自动化测试通过不等于已经在你的 Chrome / Edge 中完成实机验收。**

## 安装一次

1. Chrome 打开 `chrome://extensions`，或 Edge 打开 `edge://extensions`。
2. 开启“开发者模式”，选择“加载已解压的扩展”。
3. 选择本目录 `<local-project-directory>`，不是项目根目录。
4. 将 Career Queue 扩展固定到工具栏。后续代码更新后在扩展页点击“重新加载”。

## 每次使用

1. 保持 Dashboard `http://127.0.0.1:4322/` 运行并登录。打开保存的职位，保存并核对逐题草稿，勾选需要使用的答案。
2. 展开“连接 Chrome / Edge 填写助手”，确认读取本职位答案，生成并复制临时配对码。三分钟有效；重新生成会使旧码失效。
3. 在同一 Chrome / Edge 打开对应 Greenhouse 官方岗位页，点击扩展，粘贴码，点“读取当前页并预览”。
4. 核对岗位及全部拟填写内容，再勾选确认并点击填写。**此时文字才会进入招聘网站，网站可能在正式提交前处理输入内容。**
5. 亲自处理电话/国家、附件、资格、披露题、验证码与最终提交。在 Career Queue 里另行记录真实提交结果。

不支持嵌入其他域名的申请表、其他 ATS 或复杂控件。可填写字段限定姓名、邮箱、LinkedIn Profile 和 Website；API 中的 Phone 在真实网页可能关联国家选择器，因此本期不自动填写。

遇到已有文字、字段缺失/重复、登录或可见验证码挑战时暂停。若发生部分填写，会报告已操作数量；请检查页面，不自动回滚或覆盖。确认码已消费后若失败，需要重新生成；已填内容必须本人处理后再尝试。

## 权限与数据

- `activeTab` / `scripting`：只在你点击扩展后访问当前页，无全网站常驻脚本。
- 唯一固定主机权限是本机 `127.0.0.1:4322`，用于配对，不读取 Dashboard 的会话 cookie。
- 不用浏览器 storage、不保存密码、不上传简历、不调用提交接口。
- 临时码在服务器内存中保存摘要；有效期三分钟，绑定账号会话、职位和草稿指纹，确认使用一次。退出登录或重启服务后失效。不要分享配对码。
- 扩展窗口关闭后预览内存丢弃；不会自动把网页状态标为已提交。
