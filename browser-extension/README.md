# 岗位读取助手

当前源码版本为0.3.8。已支持手动读取当前学校详情页、核对身份、导出JSON并在本机工作台预览确认导入。自动学校导航、批量和源码诊断入口仍属实验代码，真实门户自动流程未完成验收；不要将合成测试通过理解为真实网站成功。

## 手动学校流程

1. 自行打开学校岗位详情，在扩展点击“读取当前详情页”。
2. 若详情没有独立School ID，先返回列表读取当前列表并记住选中岗位，再自己打开原标题详情。选择24小时有效；身份冲突或登录验证出现时停止。
3. 核对编号、标题、雇主、学期、身份依据及字段原文，再下载岗位JSON。
4. 在工作台“学校职位”导入学校岗位详情，预览并明确确认。目标School ID必须属于当前账号；重复导入不重复更新，材料与提交历史保留。

读取仅覆盖可见、可识别字段，不承诺隐藏内容完整。重新打开扩展可显示上次成功结果及读取时间；失败不冒充新结果。学校提交与官网提交独立，不自动投递。

## 官网普通文本填写

Greenhouse使用工作台临时配对码；先预览、核对并确认普通文本填写。电话、附件、资格、披露及最终提交由本人处理。登录、验证码或页面变化出现时暂停，不绕过验证。

## 权限与验证

安装目录为browser-extension，勿加载历史测试夹具。保留activeTab、scripting及本机工作台访问，不增加学校持久权限、后台worker或自动调度。

- npm run test:serial：隔离回归。
- npm run test:school:ui：独立Edge合成页面验证。
- npm run test:school:selected：实验面板合成测试，不能代替真实门户验收。
- node scripts/test-filter-actions-ui.mjs：本机工作台筛选、录入、表格及文件预览的合成页面检查。

本次源码同步不会安装/重载用户浏览器扩展或访问学校账号。岗位JSON、截图、数据库、凭据、备份和运行日志不进入公开仓库。
