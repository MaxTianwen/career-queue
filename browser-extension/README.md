# Career Queue 浏览器助手 0.2.3

此前 0.1.9 已在真实Brave完成一岗可见字段读取与身份核验。结果范围为当前可见、已识别的岗位字段；不是隐藏内容或批量完整性的证明。原列表保留，返回控件尚未观察到，不自动返回或投递。

## 当前单岗流程

从已登录列表选择岗位，按需要点击网页原标题。到实际详情标签打开助手并点「读取当前详情页」，再保存结果。已有本次岗位记录时无需重新开始。opener缺失、不同或原列表关闭时，必须通过当前页面严格同源及完整身份核验才允许显式重新绑定。

点击前检查点、点击派发与关联标签观察分开记录。恢复只核对，不自动重放；明确取消/重新开始不会关闭用户标签或改申请状态。默认策略可能拦截脚本弹窗，因此不要反复点击开始，也不要暗改浏览器策略。

本机IndexedDB只保存一次试运行，24小时后读取时失效，新任务替换旧记录；请及时导出。失败可保存安全错误码及布尔诊断。不会读取credentials、cookies或隐藏表单。

## 已知数据边界

可见ID缺失时仍要求标题、独立雇主和任期完全一致。身份冲突、不足或页面变更必须停止。正文读取前在同一次页面执行中再次核对。

应用要求可能写在JD开头而不是单独字段。本机严格证据转换会保留明确的双通道要求；它不创建已提交状态或申请日期。单岗结果不能直接作为已完成的无人批量。

## 已批准的批量权限

用户已批准学校域名可选权限；必需权限仍为 activeTab、scripting 和本机工作台地址，不增加 tabs 或调试权限。原始方案见[学校批量权限方案](../docs/school-batch-permission-proposal.md)，当前实现和待验收事项见下方 0.2.0 说明。
