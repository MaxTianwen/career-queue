# Career Queue 岗位读取助手 0.3.0

加载目录为项目根下的 `browser-extension`，没有构建输出目录。请勿加载 `test/fixtures/legacy-school-extension`：那里仅存历史回归夹具。两岗当前页手动读取及本地保护导入已验证；自动开页、批量读取尚未实现。

## 学校当前页读取

1. 自行打开学校岗位详情，在该标签打开扩展，点击首屏 **读取当前详情页**。不需要旧试运行记录或本机配对码。
2. 有独立 School ID 时直接核对；没有时，返回列表，在扩展展开 **详情没有 School ID？先从列表选择**，点击 **读取当前列表**，选择目标并点 **记住选中岗位**。自己点击网页原标题打开详情，然后重新打开扩展点击 **读取当前详情页**。选择24小时有效；更换目标可点 **清除岗位选择**。
3. 结果显示编号、标题、雇主、学期、身份依据、时长字段原文、正文长度和读取时间。没有独立时长字段不等于正文没有时长；不猜月数。身份不足/冲突、登录或验证、内嵌页未读取、字段超限时停止，给出具体下一步及错误码。
4. 成功后点 **下载岗位 JSON**。在本机工作台「学校职位」展开 **导入学校岗位详情**，选择文件、**预览文件**、核对后 **确认导入岗位详情**。目标 School ID 必须已存在于当前账号；服务端再次核对标题、公司、学期、正文和时长证据。预览不会写入，重复导入不重复更新，保留已有提交历史与本人确认的Portal渠道。

关闭弹窗后可恢复最近一次成功结果，明确标记读取时间；不是自动重读当前页。新读取失败不提供旧成功文件冒充本次结果。当前页仅读可见且识别到的字段，不承诺隐藏/折叠或任意页面结构完整。不会自动打开、返回或关闭学校标签，不访问申请按钮。

## 官网填写

展开 **官网普通文本填写（Greenhouse）**，使用本机工作台的临时配对码，点击 **预览官网拟填写内容**，核对并勾选后点 **确认填写普通文本**。电话、附件、资格、披露及最终提交仍由本人完成。学校读取不使用配对码。既有中断、导航及页面字段变化保护保留。

## 诊断与权限

**问题诊断与使用说明**只显示当前安全错误码，不再提供多版本试运行、批次授权、暂停/恢复或重复开页入口。自动开页和批量读取未实现，因此不出现在本版运行流程。

权限为 `activeTab`、`scripting`、`http://127.0.0.1:4322/*`；移除学校全站可选权限声明和后台service worker。学校只在用户打开当前标签扩展并点击时读取，不申请持久访问。代码不调用权限申请/撤销，不修改已有登录、账号设置或旧批次数据库；浏览器更新权限行为由浏览器处理。

旧实验模块和原弹窗已移出安装目录，保存在历史测试夹具与本机修改前备份中。不要把历史批次测试通过当作当前真实门户批量成功。

## 验证命令

- `node --test test/school-current-page.test.mjs test/school-capture.test.mjs test/v2-browser-fields.test.mjs test/v2-fill-rehearsal.test.mjs`
- `npm run test:school:ui`：用户电脑隔离Edge，真实弹窗模块/IndexedDB，浏览器API与岗位使用合成替身。
- `npm run test:school:native`：用户电脑隔离Edge，真实MV3 ISOLATED注入，localhost合成页面和学校地址替身。测试扩展临时权限只限本地测试源；不加载或重载用户扩展。
- `npm run test:serial`：完整回归，历史实验回归仅作历史兼容资料。

详见 [精简规格与验收](../docs/extension-cleanup-spec.md)。岗位JSON、日志、数据库、备份仅存本机，不提交公开仓库。
